## What's new
- The header now says Tech Evolution Tycoon
- Eras run in historical order. New rows: Paper Mill, Glassworks, Filament Forge, and Germanium Refinery. Their icons are placeholders for now
- Vacuum Tubes are made from glass, copper, and filament. Transistors are made from germanium
- A manager unlocks once you own enough of that row
- New games, prestige, challenges, and timeline forks start with $0
- Google Play Games sign-in and cloud save are optional. They only turn on in the Google Play version, once that version is set up. Open MORE, then SETTINGS, then ACCOUNT. Until then, that panel points you to Save Backup

## Important if you sideloaded the old app
- The app's package changed from com.techevolutiontycoon.game to tech.evolution.tycoon, so this APK installs as a separate app next to the old one. It does not replace 0.0.14
- Open the old app. Tap MORE, then SETTINGS, then SAVE BACKUP, then EXPORT SAVE. Copy the code and keep it somewhere safe
- Install 0.0.15. In the new app, open MORE, then SETTINGS, then SAVE BACKUP, then RESTORE FROM A CODE. Paste the code, tap CHECK CODE, then REPLACE MY SAVE
- When your empire is back, uninstall the old app
