## What's new
- This update installs over 0.0.16. The package is still tech.evolution.tycoon
- Timber Camp is the first row. Trees make wood, and the Paper Mill uses that wood. Its icon is a placeholder for now
- Older saves keep every row. If you already have a Paper Mill, a Timber Camp is started for you, with its manager and some wood
- The news ticker only shows headlines for eras you have reached
- New games get a short tutorial on the Game screen. You can skip it. It does not add money or speed. Saves that already have progress skip it
- Replay it any time: MORE, then HOW TO PLAY, then REPLAY TUTORIAL

- More events from real history: Moore's Law, the first computer bug, chip shortages
- A look and sound for each era
